# GymManagementSystem

## Prerequisites
Ensure you have the following installed on your local machine:
* **Docker**
* **Docker Compose**

## Getting Started

Follow these steps to get the application up and running on your local machine.

### 1. Clone the Repository
First, clone this repository using Git and navigate into the project directory:
```bash
git clone https://github.com/Sonarr10/GymManagementSystem.git
cd GymManagementSystem
```

### 2. Start the Application
Run the following command to build the Docker images and start the containers:
```bash
docker compose up --build
```

Once the build process completes, your application will be active and running inside the Docker environment.

```bash
http://localhost:5000/
http://localhost:5000/scalar
```
